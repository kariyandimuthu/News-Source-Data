# News Source Data — Android தொடக்கத் திட்டம்

இந்தத் திட்டம் புதிய, தனியான Android செயலிக்கான தொடக்கக் குறியீடு. இது பழைய Floot திட்டத்தையோ Supabase தரவுகளையோ அணுகவோ மாற்றவோ செய்யாது.

## இதில் உள்ளவை
- Kotlin + Jetpack Compose UI
- Room / SQLite உள்ளூர் தரவுத்தளம்
- செய்திகள், அசைன்மென்ட்கள், தொடர்புகள் ஆகியவற்றுக்கான அடிப்படைச் சேமிப்பு
- GitHub Actions மூலம் debug APK உருவாக்கும் workflow
- புதிய நிறுவலில் வெற்றுத் தரவுத்தளம்

## முக்கிய வரம்புகள்
- இந்த ZIP-இல் APK ஏற்கெனவே உருவாக்கப்படவில்லை.
- Offline AI மாதிரி இன்னும் இணைக்கப்படவில்லை; UI-ல் அது அடுத்த கட்டமாகக் குறிப்பிடப்பட்டுள்ளது.
- இந்தத் திட்டத்தை GitHub repository-க்கு upload செய்து Actions workflow இயக்க வேண்டும்.
- Debug APK-ஐ சோதனைக்கு நிறுவலாம். நீண்டகாலப் பயன்பாட்டிற்கு release signing key-ஐ பாதுகாப்பாக உருவாக்கி காப்புப் பிரதி எடுக்க வேண்டும்.
- தரவு Android app private storage-ல் இருக்கும்; app uninstall அல்லது device reset செய்தால் தரவு இழக்கப்படலாம். அதனால் export/backup அம்சம் அடுத்த கட்டத்தில் சேர்க்கப்பட வேண்டும்.
- GitHub Actions இலவச பயன்பாட்டிற்கு கணக்கு/களஞ்சிய வரம்புகள் பொருந்தலாம்.

## APK உருவாக்குவது
1. GitHub-ல் புதிய repository உருவாக்கவும்.
2. இந்த ZIP-இன் உள்ளடக்கங்களை repository-க்கு upload செய்யவும்.
3. Actions tab திறந்து `Build Android APK` workflow-ஐ இயக்கவும்.
4. வெற்றிகரமாக முடிந்ததும் `NewsSourceData-debug-apk` artifact-ஐ பதிவிறக்கவும்.
5. ZIP-ஐ extract செய்து `app-debug.apk`-ஐ Vivo Y31-ல் நிறுவவும்.

## அடுத்த கட்டங்கள்
1. JSON export/import backup.
2. செய்தி தேடல், மாவட்டம்/காவல் நிலைய வகைப்படுத்தல், edit/delete.
3. சோதிக்கப்பட்ட சிறிய offline AI மாதிரியைச் சேர்த்தல்.
4. தமிழ் AI தரம், RAM பயன்பாடு, storage பயன்பாடு ஆகியவற்றை சாதனத்தில் சோதித்தல்.
